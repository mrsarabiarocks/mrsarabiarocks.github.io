# MrsArabiaRocks.com

Website for Michaela Arabia, The Balanced Teach (@middle_teacher_syndrome).

- `index.html` is the live page. `covers/` holds product images.
- `_source/` holds the files the page is built from. All products, links, and videos live in `_source/content.py`.

## Free Claude Guide page
- Lives at /free-claude-guide/. Built by `python3 _source/guide.py .` (content is in the lists at the top of guide.py). Set WAITLIST_URL in guide.py once the ThriveCart $0 waitlist product exists.
